# Good Mobile — панель лидеров и администрации

Готовый Railway-проект без Python, SQLite и тяжёлых npm-модулей. Запуск: `npm start`.

Переменные Railway:
- `ADMIN_LOGIN` — логин первого администратора (по умолчанию admin)
- `ADMIN_PASSWORD` — пароль первого администратора (по умолчанию ChangeMe123!)

Возможности: Лидер/Заместитель, 11 фракций, профили и аватары, новости, МП, задания, нормы, создание лидеров и админов, роли КУРАТОР/ЗГС/ГС/СА/ЗГА/ГА/Рук.проекта, блокировки, выговоры, смена фракции, назначение лидером/админом, увольнение, журнал действий.

Важно: `data.json` хранится локально. Для продакшена с гарантией сохранности данных подключи PostgreSQL.
