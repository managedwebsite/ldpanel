# Good Mobile — панель управления

Готовый Node.js проект для Railway.

## Что есть
- Панель лидеров и заместителей
- 11 фракций
- Профили с аватаром и изменением ника
- Новости, МП, задания и нормы
- Админ-панель
- Создание администраторов и руководителей
- Блокировка, увольнение, смена фракции и назначений
- Выговоры с типами **Устный / Письменный**
- Причина и дата каждого выговора
- Снятие конкретного выговора
- Журнал действий
- Зеленая тема
- SVG-иконки вместо эмодзи/символов
- Адаптация под телефон

## Railway
Добавьте Variables:
- `ADMIN_LOGIN` — логин первого администратора
- `ADMIN_PASSWORD` — пароль первого администратора
- `SESSION_SECRET` — необязательная дополнительная переменная для вашего окружения

Запуск: `npm start`
